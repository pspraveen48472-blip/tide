TIDE LAUNCHER (Android TV, classic style)

BUILD (on a PC)
1. Install Android Studio. File > Open > choose this TideLauncher folder.
2. Wait for "Gradle sync" to finish (needs internet the first time).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK path: app/build/outputs/apk/debug/app-debug.apk

INSTALL
5. Copy app-debug.apk to the pen drive, plug into the TV, open it with a file manager, install.
6. Press Home on the remote and choose "Tide Launcher" > Always.

KEYS
Menu / Settings key = options panel. Back = drawer to home.
